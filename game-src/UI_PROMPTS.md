# Voltworks: Opening-screen image prompts

Each prompt is complete. Copy the whole block into your image tool. Make the background first, then attach it as a style reference when you make the logo and buttons so the colours match.

**Shared look:** futuristic sci-fi, electric blue and gold, glowing neon energy like the gameplay wires (bright white-hot core, coloured glow, fine hairline lightning).

---

Save as `title_bg_portrait.png`
