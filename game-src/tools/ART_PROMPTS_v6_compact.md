# Voltworks: compact sci-fi machine prompts (v6)

The goal is the Electric Box look, made modern. Every machine is small and compact, fits inside one square, and has its own outline and colour. You should be able to tell any two machines apart from their silhouette alone.

## How to use

1. Paste the **style block** first, then add one machine line after it.
2. Generate each image as a **1:1 square, 1024×1024, on a transparent background** (or a plain flat #00FF00 green, and I'll cut it out).
3. Save each file under the name shown in **bold**. Send me the files as a zip and I'll drop them into the game.

## Style block (paste before every machine)

> Single game asset for a mobile puzzle game, sci-fi theme. A compact, chunky machine seen from the front with a very slight top-down angle. The machine fills about 80% of the square and stays fully inside the frame. Clean modern stylized 3D render, smooth rounded shapes, gunmetal and dark graphite casing, crisp bevelled edges, small neon accent lights. One bold signature colour per machine. Simple readable silhouette that still reads at 48 pixels. No base, no plinth, no platform, no floor, no shadow on the ground, no background, no text, no letters, no logos. Centered, isolated on a transparent background, soft studio lighting, high detail but not busy.

## Parts that turn

The game turns these parts itself, so draw each of them **facing RIGHT**, with the business end on the right edge: fan, chargefan, laser, drill, chargelight, kettle, pushbot, pullbot, carrierbot, hamster, cannon.

## Tips for a consistent set

- Generate them all in **one session** using the same style block. This keeps the lighting and materials matched.
- If a machine comes out too tall or wide, add: *"make it more compact and squat, it must fit inside a small square tile."*
- If a base or floor appears, add: *"floating, absolutely no base or ground."*
